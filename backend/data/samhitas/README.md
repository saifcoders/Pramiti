# Classical Samhita Texts

Place digitized PDF and text corpora of classical Ayurvedic Samhitas here:

1. **Charaka Samhita** (*Sutra, Nidana, Vimana, Sharira, Indriya, Chikitsa, Kalpa, Siddhi Sthana*)
2. **Sushruta Samhita** (*Sutra, Nidana, Sharira, Chikitsa, Kalpa, Uttara Tantra*)
3. **Ashtanga Hridaya** (*Vagbhata*)

### Supported formats
- Structured `.json` / `.jsonl` shloka mappings (with Sanskrit Devanagari and IAST transliterations)
- `.txt` or `.pdf` translations
