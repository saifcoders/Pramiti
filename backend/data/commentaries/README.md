# Classical Commentaries (Bhashyas & Tika)

Store authoritative commentaries on the Samhitas here:

- **Ayurveda Dipika** by *Chakrapani Datta* (on Charaka Samhita)
- **Nibandha Samgraha** by *Dalhana* (on Sushruta Samhita)
- **Sarvanga Sundara** by *Arunadatta* (on Ashtanga Hridaya)
- **Ayurveda Rasayana** by *Hemadri* (on Ashtanga Hridaya)

These texts resolve ambiguities, dialectical variations, and clinical nuances.
